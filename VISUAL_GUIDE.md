## Mobile Responsive

All pages are fully responsive and adapt to mobile screens:
- Dashboard stats stack vertically on mobile
- Tables become scrollable
- Quick links remain easily tappable
- Settings form remains usable on small screens

## Color Scheme

The plugin uses WordPress default color scheme:
- Primary Blue: #2271b1 (WordPress admin blue)
- Success Green: #46b450
- Warning Orange: #f0b849
- Text Gray: #646970
- Border Gray: #c3c4c7
- White backgrounds with subtle borders

## Icons

Uses WordPress Dashicons and emoji for visual elements:
- 📦 Products
- 🛒 Orders
- 👥 Customers
- 📊 Analytics
- ⚙️ Settings
- ⚠️ Warnings
- ⭐ Popular items
- 💡 Recommendations
